# Contrato de execução dos agentes

1. Ler `docs/BLUEPRINT.md`, `docs/STATUS.md` e skills relevantes antes de escrever código.
2. Projeto clean-room: nunca consultar ou copiar o repositório antigo.
3. Feature só termina com comportamento real, persistência/reabertura quando aplicável, testes e screenshot para UI.
4. Trabalhar numa branch por Issue e abrir PR; `main` não recebe código direto após bootstrap inicial.
5. Proteger dados de alunos; usar exclusivamente dados sintéticos nas evidências.
6. Não simular build ou aprovação: apontar resultado e o que falta verificar.
7. Não introduzir biblioteca sem necessidade e licença revisadas.
