# Produto — Assistente Pedagógico

Sistema pessoal do professor para Android: planejamento → aula → frequência → atividades → avaliação → registros → relatórios → próximo planejamento. Registrar uma vez, reutilizar com segurança. Não transformar o produto num ERP escolar nem num grande formulário.

Navegação prevista: Hoje, Turmas, Planejamento, Arquivos, Mais. Etapas visíveis: Educação Infantil, Ensino Fundamental (1º a 9º como atributo da turma), Ensino Médio. Sem login obrigatório, sem anúncios, dados locais por padrão.

Free: até 2 turmas ativas, alunos ilimitados nessas turmas, ciclo real de uso e backup/restauração próprios. Pro: turmas ilimitadas e recursos avançados. Downgrade nunca remove ou oculta histórico.
